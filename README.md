
🌍 Trippy AI — AI-Powered Travel Assistant

Trippy AI is an interactive AI-powered travel assistant built with Python and Streamlit. It helps users plan their trips, explore travel destinations, estimate budgets, check weather conditions, and get personalized travel recommendations through a conversational chatbot.

The project uses the Groq API to generate AI-powered responses and Open-Meteo to retrieve weather information. It also provides quick access to flight and hotel search websites, making travel planning easier from one interface.

✨ Features:

- 🤖 AI Travel Chatbot:** Get personalized travel suggestions and answers to travel-related questions.
- 🧭 Travel Missions:** Choose from different planning options based on your travel needs.
- 📍 Destination Discovery:** Explore destinations based on your preferences and travel goals.
- 💰 Budget Planning:** Get estimated travel expenses and budget suggestions in Pakistani Rupees (PKR).
- 🗓️ Itinerary Planning:** Generate travel plans according to your destination, duration, and preferences.
- 🌦️ Live Weather Information:** Check current weather and available forecast information using the Open-Meteo API.
- ✈️ Flight Search:** Open Google Flights to explore available flight options.
- 🏨 Hotel Search:** Open Booking.com to explore accommodation options.
- 💬 Conversation History:** Keep track of messages during the current app session.
- 🔄 Flexible Trip Planning:** Ask the chatbot to adjust your travel plan when your requirements change.

 🛠️ Technologies Used

- Python — Core programming language
- Streamlit — Interactive web application interface
- Groq API — AI-powered chatbot responses
- Requests — API communication and HTTP requests
- Python-dotenv — Secure loading of environment variables
- Open-Meteo API — Weather and forecast information
- Google Flights — External flight search
- Booking.com — External hotel search

* Project Objective

The objective of Trippy AI is to make travel planning simpler and more accessible by combining conversational AI, budget estimation, itinerary suggestions, weather information, and external travel search tools in one user-friendly application.

This project demonstrates the practical use of :
- Python
- API integration.
- Environment variables.
- AI-powered conversational systems.
- Streamlit application development.

Developed as a Python and AI project to explore the development of interactive AI-powered applications.
